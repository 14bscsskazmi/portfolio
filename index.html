Elvinci.de GmbH, NurembergTech lead, full stackB2B returns trading

B2B returns trading platform

A multi-role order management system for buying and selling customer returns of white goods and electronics at wholesale scale.

Problem

Sales, back office, warehouse, suppliers and buyers worked on the same orders through separate tools and manual handoffs. The business needed one system with the right view and permissions for each group.

What I built

  • Led the design of a multi-role portal platform in React and TypeScript: admin, sales, back office, suppliers, buyers and warehouse each get their own workspace with granular RBAC.
  • Built and extended the Django REST APIs behind it, including automated B2B invoicing, on PostgreSQL.
  • Owned the backlog and decided sprint scope by business impact.
  • Set up CI/CD with GitHub Actions and Docker from dev to production, plus server deployment.
  • Mentored a junior developer through code reviews and AI-assisted development.

Cross-team workflow automation

n8n pipelines that connect MS Teams, Jira, email and the order database.
